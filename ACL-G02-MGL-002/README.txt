MEGALON / RELEASE 2026-09-11

追補修正
ARCHIVEからCLASSIFIEDへ戻る場合、同じタブで認証済みのセッションを引き継ぎ、起動認証を繰り返しません。
新規タブ・新規セッション・RECONNECT時だけ最初の認証画面を表示します。
PC版の予告編は通常の公式YouTube埋め込みへ変更し、公開元情報を渡して再生互換性を改善しました。
埋め込みが端末や動画側の設定で制限される場合も、直下の「東宝公式チャンネルで開く」は利用できます。
ARCHIVEの見出し・登録表・作品カード・本文セクションの上下余白を共通の間隔へ整理しました。
ARCHIVEへの接続確認音を追加し、入室時とCLASSIFIED復帰時を暗部から徐々に表示するよう変更しました。
認証済みのCLASSIFIEDへ戻った後は、メガロへの最初のタップ内で音声回路を起動して鳴き声を再生します。
ARCHIVEを暗い保存庫・古い手記に寄せ、1973年公開時ポスターの資料表示を追加しました。
作品情報の参照先を日本語版Wikipediaへ変更しました。

配置

index.htmlを上書きし、archive.html、terminal-session.js、terminal-session.css、archive-imagesを追加します。
既存のNFC登録URLはそのままで使えます。index.htmlだけをアップロードしないでください。
公開後は既に開いているタブを閉じ、新しいタブでアクセスすると版を確認しやすくなります。

タイマー
最初のページ読み込み時を起点に同じタブで共有。
5分：小さな認証警告。10分：不正アクセス確定、短い画面干渉。15分：強制切断。
ページ移動や再読み込みではリセットしません。RECONNECTで新しいセッションを開始。
実際の位置情報取得・端末識別・監視やサーバーへの記録送信は行っていません。文言は演出です。

館長コメント
archive.html内で「★ 館長コメント」を検索。curator-comment内の文章を変更します。

収蔵品追加
「★ ITEM START」から「★ ITEM END」のarticleをコピーし、対象作品のcollection-gridの中へ貼り付けます。
templateタグはコピーしません。写真・品名・分類・年代・メモを変更してください。
実際の収蔵品と館長手記は未提供のため、空の記録としてあります。

画像変更
archive-imagesに画像を追加。収蔵品のimg srcを「./archive-images/画像名.jpg」へ変更。
推奨1200×1200px。正方形の枠に全体が収まるため、縦長・横長でも勝手に切り取りません。
作品一覧画像はwork-fileのdata-imageを変更します。
映画ポスターはarchive.html内の「★ 映画ポスター」を検索し、archive-images内の画像へ差し替えます。

予告編変更
「★ YouTube URL」を検索し、data-youtube-urlを公式YouTube動画のURLに変更。
サムネイルと外部リンクは自動追従。空欄なら映像資料未登録となります。
動画は再生ボタンを押したときだけ読み込みます。埋め込みが制限された場合は下の公式チャンネルリンクを利用できます。

作品追加
「★ WORK START」～「★ WORK END」のarticleを複製し、idを重複しない名前へ変更。
data-title / data-year / data-note / data-imageと本文を変更します。
登録作品数・一覧・前後移動は自動で更新されます。

確認範囲
JavaScript構文、ローカル参照、元画像・音声データの一致、5/10/15分の境界、ページ間時刻引き継ぎ、再接続をコード上で検証。
iPhone実機での見た目・鳴き声・音量、およびYouTubeの実再生は未検証です。
周波数補正はアクセス電子音の聴感差を抑える対策で、全端末での同一音量を保証するものではありません。
